# Shaik Saleem — Portfolio

A responsive, single-page portfolio for Shaik Saleem, built with plain HTML, CSS, and JavaScript. It highlights his verified resume history and expands on the banking, aviation, workflow automation, and CRM projects described for this portfolio.

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Included

- Responsive layout with mobile navigation
- Filterable project portfolio with module-level descriptions
- Skills, experience, education, awards, and contact details
- Direct email/phone links and a downloadable resume
